# Personal Website Starter

A minimal, responsive personal website starter prefilled for Askenas Kiprono. Files created:

- `index.html` — main page with hero, about, projects, contact
- `styles.css` — simple responsive styles
- `script.js` — small UI helpers

How to use

1. Open `index.html` in your browser to preview.
2. Edit the placeholders (name, bio, projects, links) in `index.html`.
3. To publish, push this repo to GitHub and enable GitHub Pages from the repository settings (use `main` branch / `docs/` or root).

Want help customizing content or adding a contact form/backend? Reply with your name, bio, and links and I will update the site.
